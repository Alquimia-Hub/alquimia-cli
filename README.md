# alquimia

CLI de la comunidad [Alquimia](https://alquimia.community/) — IA, automatización y productividad.

## Install

Package source: github:Alquimia-Hub/alquimia-cli

Example:

    npm install -g github:Alquimia-Hub/alquimia-cli

## Usage

- alquimia info
- alquimia help
- alquimia version
